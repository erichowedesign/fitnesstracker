# Foundation

Personal strength training for iPhone. Workouts stay on the device.

This first slice is **Upper Push** (Routine A) in SwiftUI, using system Liquid Glass on iOS 26 (`glassEffect()`, `.glassProminent`, glass navigation and bottom bar). Weight editing is intentionally omitted until that UI is designed.

## Run

1. Open `FitnessTracker.xcodeproj` in Xcode 26.
2. Choose an iPhone simulator.
3. Run the **Foundation** scheme.

Seed lifts come from `FitnessTracker/workouts.json`. Line drawings are the Everkinetic / Bryl Lim SVGs (CC BY-SA 4.0). The Upper Push wash is `FitnessTracker/background-videos/AdobeStock_621992661.mp4`, played at 0.4× with a thermal color map.
